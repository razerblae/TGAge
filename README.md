# TGAge Anonymous Code Release

This repository contains the anonymized core implementation of TGAge, a second-generation phenotypic biological aging clock based on tabular foundation model.

## Scope

This repository is prepared for double-blind peer review. It includes the core model implementation only.

The data used in this study is private and thus is not included. No raw data, processed data, model outputs, trained models, logs, or identifiable information are provided.
